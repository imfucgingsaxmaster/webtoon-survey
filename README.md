# Webtoon Radar

네이버웹툰 **공개 정식 작품 카탈로그 전체**를 매주 조사하는 Python · Streamlit · SQLite 프로젝트입니다. 요일별 연재작, 매일+, 완결 목록을 모두 순회하고 작품 ID로 중복을 제거합니다. 특정 인기작 표본이나 첨부 조사 PDF의 작품 목록으로 대상을 제한하지 않습니다.

## 결과물과 실행

```sh
pip install -r requirements.txt
python -m unittest tests -v
python radar.py
streamlit run app.py
```

저장된 관측만 분석할 때는 `python radar.py --offline`을 실행합니다. 대시보드는 네트워크 수집 없이 저장된 실제 관측을 읽습니다.

- 웹 대시보드: 작품명·작가 검색, 상태·목록 필터, 공개 별점, 수집 범위 검증, Excel 다운로드
- Excel: 전체 작품, 목록별 인기순 위치, 범위 검증 및 출처
- 요약 PDF: 작품 수·상태·수집 범위와 제한사항
- SQLite: 관측 시점별 작품 및 목록 소속, JSON: 재현 가능한 원자료 메타데이터
- 주간 비교: 이전 관측 대비 목록 진입·이탈, 같은 목록 내 위치 변화. 첫 실행에서는 추세를 만들지 않습니다.

## 수집 범위와 자료 원칙

출처는 [네이버웹툰 공개 목록](https://comic.naver.com/webtoon)입니다. 공개 웹사이트가 제공하는 JSON 목록을 이용하며 공식 계약형 API라고 주장하지 않습니다. 작품 ID, 제목, 작가, 공개 별점, 연재 상태, 목록 내부 위치만 보관합니다. 정식 공개 목록 밖의 베스트도전·도전, 비공개·판매 종료·앱 전용 작품까지 포함한다는 의미는 아닙니다.

수집 전 [robots.txt](https://comic.naver.com/robots.txt)를 다시 확인하고 허용된 목록 경로만 초당 최대 1회 요청합니다. 본문·이미지·댓글·개인정보를 수집하지 않으며 로그인·쿠키·보호장치 우회를 사용하지 않습니다. 차단·제한·응답 구조 변경·누락·페이지 중복이 발견되면 실패로 처리하고 기존 정상 관측을 유지합니다. robots 허용은 별도 이용허락이나 무제한 재사용 허가를 뜻하지 않습니다. [이용약관](https://member.webtoon.naver.com/policy/terms)을 준수하는 비상업 과제용 메타데이터 조사이며 정책 변경 시 수집을 중단하고 재검토해야 합니다.

완결 목록은 응답의 총 작품 수와 모든 페이지 수를 대조합니다. 요일별·매일+는 응답 배열 전체를 읽습니다. 수집 중 목록 변동이 발견되면 결과를 게시하지 않습니다. 여러 요청의 결과이므로 수집 시작·종료 시각 사이의 관측입니다.

공개 별점은 이용자 평가이며 조회수·매출·이용자 수가 아닙니다. 인기순 위치는 해당 목록 내부 정렬 순서입니다. 요일 간 위치를 합산한 통합 순위나 공개되지 않은 지표를 생성하지 않습니다. 목록 진입·이탈을 곧바로 신작·서비스 종료로 해석하지 않습니다.

## 네이버시리즈

[시리즈 robots.txt](https://series.naver.com/robots.txt)는 만화 전체 분류 경로의 자동 접근을 제한합니다. 따라서 현재 시리즈 전수 수집은 **대기**이며 허가된 피드나 제공 자료가 확보되면 별도 수집기를 연결합니다. 웹툰 관측으로 시리즈 통계를 대신하지 않습니다.

## 주간 자동 실행

GitHub Actions `Weekly Webtoon Radar`: 매주 월요일 **09:17 한국시간** 및 수동 실행. 테스트 → 공개 목록 수집 → SQLite/Excel/PDF 생성 → 관측 이력 저장 → 산출물 업로드 순서입니다. `catalog_latest.json`과 압축된 `history/`만 봇이 갱신합니다. 산출물은 Actions 실행 화면의 Artifacts에서 내려받습니다(90일 보존). 관측 이력은 저장소에 보존하며 다음 실행에서 SQLite를 재구축합니다. GitHub 예약 작업은 지연될 수 있고 비활성 공개 저장소의 예약 실행이 중단될 수 있습니다.
